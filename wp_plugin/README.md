# Selleye Apify Import

Импорт данных из Apify-датасетов в WordPress по расписанию.

## Установка
1. Скопировать `selleye-apify-import.php` в `wp-content/plugins/` (или в папку `selleye-apify-import/`).
2. Активировать в «Плагины».
3. Настройки → Apify Import.

## Настройки
- **Apify API token** — токен из apify.com (Account → Integrations).
- **Dataset ID или act~ID** — id датасета (`AbCdEf...`) либо id актора —
  тогда берётся выдача последнего успешного прогона.
- **Маппинг (JSON)** — соответствие полей. Ключи целей:
  `post_title`, `post_content`, `post_status`, `url`, `sku`, любые `meta_*`.
  Вложенные поля источника — через точку (`attrs.color`). Варианты
  проверяются по очереди, первый непустой wins.
- **Дедупликация** — колонка результата (обычно `url` или `sku`):
  повторная выгрузка того же товара обновляет пост, а не плодит дубли.
- **Расписание** — WP-cron: от 15 минут до раза в день.
- **Лимит** — макс. items за прогон.

## Поведение
- Каждый прогон: dataset → маппинг → upsert постов (создать/обновить).
- Ключ дедупликации хранится в meta `sai_dedup`.
- Лог последних 50 прогонов — на странице настроек.
- Новые посты создаются в статусе draft/publish/pending (настраивается).
